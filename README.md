# Карманные тузы

Тренажёр техасского холдема для телефона: стол с ботами разных стилей и тренер, который объясняет каждый ход.

**Играть:** https://aivan-py.github.io/poker-trainer/ — в Chrome на Android откройте меню ⋮ → «Установить приложение».

- Тренер советует ход и объясняет: сила руки, позиция, ауты, эквити, пот-оддсы.
- Разбор решений после каждой раздачи.
- «Что было бы»: после фолда показывает доигровку и настоящий шанс выиграть с учётом карт соперников.
- Режим «Чаще собирать комбинации» для запоминания комбинаций.
- Работает офлайн после первого открытия.

## Разработка

```bash
npm start   # локальный сервер на http://localhost:8000
npm test    # тесты движка, оценщика рук, тренера
```

Чистый JavaScript (ES-модули), без сборки и зависимостей.
